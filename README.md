# SpeakEasy downloads

Installers for **SpeakEasy**. You need a license key to use the app.

## Download the latest version

| Computer | File |
|---|---|
| Mac with Apple M1 / M2 / M3 / M4 chip | [SpeakEasy-Mac-AppleSilicon.dmg](https://github.com/AnuragBatham/speakeasy-downloads/releases/latest/download/SpeakEasy-Mac-AppleSilicon.dmg) |
| Mac with Intel processor | [SpeakEasy-Mac-Intel.dmg](https://github.com/AnuragBatham/speakeasy-downloads/releases/latest/download/SpeakEasy-Mac-Intel.dmg) |
| Windows 10 / 11 (64-bit) | [SpeakEasy-Windows.exe](https://github.com/AnuragBatham/speakeasy-downloads/releases/latest/download/SpeakEasy-Windows.exe) |

Not sure which Mac you have? Apple menu › **About This Mac**: "Chip: Apple M…" means Apple Silicon, "Processor: Intel" means Intel.
